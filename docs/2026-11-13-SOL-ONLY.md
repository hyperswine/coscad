# Sol-only main branch (2026-11-13)

The [final legacy source release](https://github.com/hyperswine/coscad/releases/tag/legacy-scripts-final-2026-11-13)
preserves committed source 37f3577 and a supplemental archive of the existing
Python/Sol migration source. The overlay is development work, not a qualified
binary release. The v1.6.0.0 binary release remains unchanged.

Main removes all 205 tracked Python/shell files. Nineteen additional untracked
Python migration helpers/tests were archived and removed from the working tree.
The [removal manifest](2026-11-13-SOL-ONLY-REMOVALS.json) lists them, together with
retired environment pins, dependency lists and the old manual update job.

This is deliberate retirement, not a completed port of every removed feature.
The native compiler, geometry kernel, Haskell regression suite and JavaScript
editor tests remain. Existing .coscad/.assemble sources, meshes, print packages
and physical outcome records are preserved. Unrelated local model/printing
changes remain uncommitted.

## Supported Sol workflows

Use FP-RISC 0.13.1's Sol executable, or set SOL to that runner. Run from the repo:

- scripts/sol-only-check.sol: enforce the Python/shell file policy.
- scripts/check-docs.sol: CLI/manual/README and module-map agreement.
- scripts/package-release.sol: native binary archives, metadata, notices and hashes.
- scripts/bonded-shelf.sol and scripts/assembly-region-preview.sol: experimental
  bonded-input generation and preview rendering.
- scripts/render-boats.sol: native boat mesh rendering.
- scripts/slice-prepared.sol: offline slicing of already prepared jobs. It does
  not replace package verification, printer safety checks or LAN dispatch.
- scripts/update-formula.sol: Homebrew formula update tooling.
- models/egg-box/generate.sol, models/tank-model-2020/prepare-panel.sol,
  models/twin-boat-trials/design.sol and models/print-in-place-globe/v2-threaded/generate.sol:
  model/coupon source generation, with the globe's shared workflow.sol library.
- models/tesseract-v3-threaded/export.sol and instructions.sol: model exports and
  joint-instruction generation; the native planner test now calls Sol directly.

The self-contained ports were selected from the pre-existing local migration.
Unfinished Sol wrappers that still invoke Python helpers are not included in
the commit or source-distribution input list. They remain recoverable from the
release overlay; any existing local copies are unfinished work, not supported main.

## Retired until replaced

Python-dependent project preparation/verification, sliced-mass analysis,
reference-FEA comparisons, automatic model build/finalization, pipeline pinning,
editor-icon regeneration, printer dispatch/monitoring, and the atomic manual
publisher are archived. The old automatic manual update job is removed from
source; this task does not deploy or modify the served manual.

The replacement CI keeps native geometry tests, including the independent
OpenSCAD/BOSL2 oracle job, the no-OpenSCAD job and editor checks. Removed Python
pin, Bambu/preflight and mass-analysis tests are no longer claimed as coverage.
CI and binary releases use a pinned Sol runner: the checksum-verified macOS
0.13.1 release, or a pinned FP-RISC source build on Debian trixie for Linux.
Native build bootstrap and CI setup still use standard external build tools;
this policy concerns repository-owned Python/shell script files.
